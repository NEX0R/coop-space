# WebApp Collaborativa

## Struttura del Progetto
```
├── frontend/  
│   ├── public/  
│   └── src/  
├── backend/  
│   ├── controllers/  
│   └── models/  
├── render.yaml  
└── README.md  
```

## Requisiti
- Node.js
- MongoDB o PostgreSQL

## Installazione
1. Clonare la repository
2. Eseguire `npm install` sia in frontend che backend
3. Configurare le variabili d'ambiente

## Avvio
- Frontend: `npm start`
- Backend: `node server.js`

## Deploy su Render
1. Collegare l'account GitHub
2. Selezionare la repository
3. Il deploy verrà avviato automaticamente grazie al file render.yaml
